## Spine Animation Studio

An [ImGui](https://github.com/ocornut/imgui) based tool for Spine skeletons,
built twice: as a desktop application and, from the very same sources, as a
WebAssembly module that runs right here.

**[Open the studio](/studio/)**

Drag a Spine export into it — the skeleton file, its `.atlas` and its page
images — scrub the timeline, then export an animated GIF. Both the 3.8 and the
4.2 Spine runtimes are supported in one build.

Nothing is uploaded: the files you choose are read inside the tab, and the GIF
comes back as a download.

### Requirements

A browser with **WebGL 2** — anything released since 2017 has it.
